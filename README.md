# Storage Health & Capacity Dashboard

## Project Overview
An interactive web dashboard that monitors storage capacity, health status, and predictive exhaustion timelines across enterprise storage systems. Combining enterprise storage administration experience with modern front-end development, the application enables real-time capacity planning, threshold-based health alerts, and operational load simulations.

## Features
* **Multi-System Capacity Monitoring:** Displays used, available, and total storage capacity alongside real-time health status indicators across multiple storage systems.
* **AI Capacity Run-Out Predictor:** Uses JavaScript algorithms to dynamically calculate and forecast storage pool exhaustion dates based on operational usage trends.
* **Interactive Scenario Switcher:** Replaces static inputs with dynamic load simulation presets, allowing users to test varying operational workloads and evaluate capacity impact in real time.
* **Interactive Dell Storage Controls & Validation:** Supports live capacity updates, utilization calculations, input validation, and threshold-based status alerts.
* **Mobile-Responsive UI & Navigation:** Features a responsive layout with a collapsible sidebar and hamburger menu toggle for seamless viewing across desktop and mobile devices.

## Technologies Used
* **HTML5** — Semantic structure and dashboard layout
* **CSS3** — Modular external stylesheet architecture, responsive design, and interactive sidebar transitions
* **JavaScript (ES6+)** — Predictive run-out algorithms, dynamic scenario switching, capacity calculations, and form validation
* **Git & GitHub** — Version control and source code hosting
* **GitHub Pages** — Static web deployment

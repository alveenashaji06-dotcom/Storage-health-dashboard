Storage Health Dashboard

A front-end project that demonstrates storage monitoring concepts through a simple dashboard interface.

Live Demo

 https://alveenashaji06-dotcom.github.io/Storage-health-dashboard/

Project Overview

This project presents sample storage capacity and health information for different storage systems. It combines my enterprise infrastructure support experience with my developing front-end skills.

Features
1) Displays sample storage capacity information for multiple storage systems.
2) Shows used, available, and total capacity.
3) Presents storage health status indicators.
4) Supports interactive capacity updates and utilization calculations for Dell storage, where implemented.
5) Demonstrates basic validation and threshold-based status updates, where implemented.

Provides a simple interface for viewing storage information.
Technologies Used
1) HTML5
2) CSS3
3) Javascript
4) Git and GitHub
5) GitHub Pages

How to Run Locally :
Clone or download this repository.
Open the project folder in Visual Studio Code.
Open index.html in a browser, or use the Live Server extension.

Storage Health Dashboard

A front-end project that demonstrates storage monitoring concepts through a simple dashboard interface.

Live Demo

 https://alveenashaji06-dotcom.github.io/Storage-health-dashboard/

Project Overview

This project presents sample storage capacity and health information for different storage systems. It combines my enterprise infrastructure support experience with my developing front-end skills.

Features

Displays sample storage information for NetApp, Pure Storage, and Dell systems.

Presents used capacity, total capacity, and health status.

Provides a dashboard interface for viewing storage information.

Includes a basic storage-related input form.

Technologies Used

HTML5

CSS3

Git and GitHub

GitHub Pages

How to Run Locally

Clone or download this repository.

Open the project folder in Visual Studio Code.

Open index.html in a browser, or use the Live Server extension.
